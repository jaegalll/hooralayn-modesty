Unsere handgefertigten Produkte können je nach Modell individuell auf deine gewünschten Maße angepasst werden.

Wie lang kann der Bambus Khimar maximal sein?

Beim Bambus Khimar sind vorne und hinten jeweils maximal 140 cm möglich.

Kann ich beim Bambus Khimar eine Farbe auswählen?

Ja. Öffne den Bambus Khimar und tippe auf das Stoffbild deiner gewünschten Farbe.

Welche Maße kann ich beim Abaya Set angeben?

Beim 2-teiligen Abaya Set kannst du die gewünschte Abaya-Länge sowie die Hijab-Länge vorne und hinten individuell angeben.

Wie wähle ich eine Stofffarbe aus?

Öffne das gewünschte Produkt und tippe auf das Stoffbild deiner gewünschten Farbe.
